쌤157 자료수집 제어

부가세 [계산하기] 진입 시 자료수집을 할지는 srt_0001_02 응답의 SCR_DAT_NEED_YN(Y=수집, N=건너뜀)으로 정해집니다. 자료수집을 다시 돌리거나 건너뛰어야 할 때 환경에 맞는 방법을 고르세요.

① 자료수집 다시 실행

당일 이미 수집한 계정으로 자료수집 화면을 다시 봐야 할 때 씁니다.

개발 당일 수집 이력 삭제

선택된 HT_TIN
새 탭에서 실행

개발 어드민(sadm.d.nux.kr)에 로그인된 브라우저에서 실행하세요. 응답에 오류가 없으면 삭제된 것이고, 다음 [계산하기] 진입 때 자료수집이 다시 돕니다.

스테이징 mitm _10 자료수집 강제 실행

_10_force_data_collectON
_10_target_service/vat/v2601/svc/srt/srt_0001_02 (기본값)

[부가세 계산하기] 누르기 직전에 켜고, 자료수집 로딩이 시작되면 바로 끄세요. 켜 둔 채 진행하면 수집이 끝나도 계속 Y가 내려와 다음 화면으로 넘어가지 않습니다.

② 자료수집 건너뛰기

가상로그인 계정은 홈택스 인증서가 없어 자료수집(menu_0002_01)이 EE009로 실패합니다. SCR_DAT_NEED_YN을 N으로 바꿔 사업장 정보 확인으로 바로 넘어갑니다. 서버 데이터는 바뀌지 않습니다.

개발·스테이징 웹 콘솔 / 북마클릿 — 일반 브라우저

  1. 가상로그인으로 홈 화면까지 들어갑니다. (가상로그인 과정에서 페이지가 새로 로드되므로 그 전에 넣으면 사라집니다)
  2. 앱 탭에서 「쌤157 자료수집 건너뛰기」 북마클릿을 누르거나, F12 › Console에 아래 코드를 붙여넣습니다. 왼쪽 아래에 「자료수집 건너뛰기 ON」 표시가 뜹니다.
  3. [부가세 계산하기]를 누릅니다. 치환되면 표시가 「적용됨」으로 바뀌고 콘솔에 [NOCOL] … Y→N이 찍힙니다.
  4. 끝나면 북마클릿을 한 번 더 누르거나 새로고침해서 해제합니다. 계정을 바꾸면 다시 적용하세요.
쌤157 자료수집 건너뛰기

적용 범위는 그 탭 하나이며, 프록시 옵션·실기기와 무관합니다. 크롬 콘솔에 처음 붙여넣을 때 경고가 뜨면 allow pasting을 입력한 뒤 다시 붙여넣으세요.

개발·스테이징 mitm _09 응답 전체 교체 — 프록시 브라우저·실기기

  1. 그 계정으로 [부가세 계산하기]를 한 번 눌러 mitmweb에서 srt_0001_02 응답 본문을 복사합니다. 계정마다 응답이 다르므로 계정을 바꾸면 다시 캡처합니다.
  2. 아래 칸에 붙여넣으면 SCR_DAT_NEED_YN만 N으로 바꾼 JSON이 만들어집니다.
  3. 홈으로 돌아가 옵션을 켜고 [부가세 계산하기]를 다시 누릅니다.

_09_mock_raw_responseON
_09_target_service/vat/v2601/svc/srt/srt_0001_02
_09_response_json위에서 만든 JSON

_11(서버 미전송)은 쓰지 않습니다. srt_0001_02가 서버에 닿아야 세션에 신고 년월이 잡히고, 건너뛰면 다음 srt_0007_02가 「신고 년월」(MoveMainPageException)로 실패해 홈으로 돌아갑니다.

계산이 끝나면 _09_mock_raw_response를 끄고 GET /options로 꺼졌는지 확인하세요. 다른 재현용 값이 들어 있었다면 켜기 전에 원래 값을 적어 두고 되돌립니다.

자료수집 자체를 검증하는 TC(COL)에는 건너뛰기를 쓰지 않습니다. srt_0001_02가 세션 오류(CE008 「로그인 정보가 만료되었어요」)로 실패하는 계정은 건너뛰기로 해결되지 않습니다. 건너뛰기는 응답만 바꿀 뿐이라, 계산 중 입력한 값(면세 매출 응답 등)은 실제로 저장됩니다.

쌤157 가상로그인

어드민 SSEM 버튼과 같은 가상로그인을 새 창 대신 새 탭으로 엽니다. 어드민에 로그인된 브라우저에서 사용하세요.

  1. 처음 한 번 아래 「쌤157 가상로그인」 버튼을 북마크바로 드래그해 저장합니다.
  2. HT_TIN을 고르고 새 탭에서 어드민 열기를 누릅니다.
  3. 열린 어드민 탭에서 저장한 북마클릿을 누르면 그 탭이 해당 계정의 앱 화면으로 바뀝니다. 어드민 로그인 화면이 뜨면 로그인한 뒤 누르세요.
선택된 HT_TIN
쌤157 가상로그인

어드민 화면은 다른 사이트의 요청을 받지 않아 이 페이지에서 바로 로그인할 수 없습니다. 그래서 어드민 탭 안에서 북마클릿이 가상로그인을 요청합니다. HT_TIN은 이 페이지가 연 탭의 이름으로 전달됩니다. 어드민을 직접 연 탭에서 북마클릿을 누르면 HT_TIN을 물어본 뒤 그 탭을 앱 화면으로 바꿉니다.

카뱅 시뮬레이터 제어

카카오뱅크 진입을 흉내 내는 시뮬레이터(tester/simulator.html)에 쓰는 북마클릿입니다. 시뮬레이터 기본 대상 /kkb는 스테이징에서도 개발 서버로 넘어가므로, 접속한 환경의 카뱅 주소로 바꿔 줍니다.

  1. 처음 한 번 아래 두 버튼을 북마크바로 드래그해 저장합니다.
  2. 환경을 고르고 새 탭에서 시뮬레이터 열기를 누릅니다.
  3. 금융인증서로 들어갈 때는 시뮬레이터에서 「카뱅 시뮬 타겟」을 누른 뒤 저장된 계정(예: 김동현)을 고릅니다.
  4. 공동인증서로 들어갈 때는 「카뱅 시뮬 공동인증서」를 누르고, 오른쪽 아래 창에서 signCert.der·signPri.key를 고른 뒤 비밀번호를 입력하고 「인증서 불러오기」 → 「공동인증서로 시작」을 누릅니다.
시뮬레이터 주소
카뱅 시뮬 타겟
카뱅 시뮬 공동인증서

시뮬레이터를 새로고침하면 대상 페이지가 원래 값으로 돌아가므로 북마클릿을 다시 누릅니다. 「다른 정보로 로그인」은 쓰지 않습니다.

공동인증서 비밀번호는 그 탭의 메모리에서만 쓰고 저장하거나 전송하지 않습니다. 서명은 브라우저 안에서 하고, 서버에는 기존 금융인증서와 같은 형식(인증서·서명값·신원확인값)으로 전달합니다. 지원하는 개인키 형식은 seedCBCWithSHA1과 PBES2(PBKDF2 + SEED)입니다.

쌤157 개발 데이터 복사

개발서버에서 한 계정(FROM)의 사업장과 데이터를 다른 계정(TO)에 복사합니다. 개발 어드민(sadm.d.nux.kr)에 로그인된 브라우저에서 사용하세요.

  1. 처음 한 번 아래 「쌤157 데이터 복사」 버튼을 북마크바로 드래그해 저장합니다.
  2. FROM·TO HT_TIN과 기존 데이터 삭제 여부를 고르고 새 탭에서 어드민 열기를 누릅니다.
  3. 열린 어드민 탭에서 저장한 북마클릿을 누르고 확인하면 복사가 실행됩니다. 어드민 로그인 화면이 뜨면 로그인한 뒤 누르세요.
FROM_HT_TIN — 데이터를 가져올 계정
TO_HT_TIN — 데이터를 복사해 넣을 계정
DEL_YN — TO 계정의 기존 데이터 삭제

직접 입력 칸에 값이 있으면 목록 선택보다 우선 적용됩니다.

쌤157 데이터 복사

어드민 서비스는 어드민 로그인 세션이 있어야 하므로 이 페이지에서 바로 실행할 수 없습니다. 그래서 어드민 탭 안에서 북마클릿이 요청을 보냅니다. 값은 이 페이지가 연 탭의 이름으로 전달되며, 어드민을 직접 연 탭에서 북마클릿을 누르면 FROM·TO·DEL_YN을 차례로 물어봅니다.

mitm 응답 변환

mitmweb에서 캡처한 응답(여러 줄로 정리된 JSON)을 mitm 옵션 _09_response_json·_11_response_json에 넣는 한 줄 JSON으로 바꿉니다. 키 삭제·값 변경도 여기서 같이 합니다.

  1. mitmweb에서 대상 flow의 Response 본문을 복사해 붙여넣습니다. 앞뒤 ```나 공백·줄바꿈이 섞여도 됩니다.
  2. Request 본문(nuts=…)도 붙여넣으면 SERVICE를 읽어 대상 서비스로 채웁니다.
  3. 지울 키·바꿀 값을 적고, 옵션 번호를 고른 뒤 결과를 복사해 mitmweb Options에 붙여넣습니다.
