쌤157 Scheme 환경별 테스트

각 케이스에서 실행 환경을 선택하세요. 선택한 환경에 따라 scheme prefix만 변경되며, 나머지 경로와 파라미터는 기존 테스트 URL과 동일합니다.
ℹ️ Android는 운영으로만 실행하세요. 이 후 실행할 서버별 앱을 선택하시면 됩니다.

개발 ssemdev://스테이징 ssemstag://운영 ssem://

정상 케이스

N-01

앱 실행

기대 동작: 앱 실행

실행 URL
ssem://run
선택 환경으로 실행
N-02

인증서 연동화면 이동

기대 동작: 인증서 연동 화면으로 이동

실행 URL
ssem://run?scheme=openModal&ELE_NM=element%3A%2F%2F.is-cert-list-check&ELE_TARGET=%2Fcomp%2Fmnu%2Fmnu_001.html
선택 환경으로 실행
N-03

쿠폰함 페이지 이동

기대 동작: 쿠폰함 페이지로 이동

실행 URL
ssem://run?scheme=openModal&ELE_NM=element%3A%2F%2F.m_cpn_101_01&ELE_TARGET=%2Fcomp%2Fcpn%2Fm_cpn_101.html
선택 환경으로 실행

오류 케이스

E-01

실행액션은 정상이나, 파라미터가 누락

기대 동작: 동작 없음, 그냥 앱 실행

실행 URL
ssem://run?scheme=openModal
선택 환경으로 실행
E-02

파라미터는 정상이나, 실행액션이 누락

기대 동작: 동작 없음, 그냥 앱 실행

실행 URL
ssem://run?scheme=&ELE_NM=element%3A%2F%2F.is-cert-list-check&ELE_TARGET=%2Fcomp%2Fmnu%2Fmnu_001.html
선택 환경으로 실행
E-03

파라미터는 정상이나, 없는 실행액션을 요청한 경우

기대 동작: 동작 없음, 그냥 앱 실행

실행 URL
ssem://run?scheme=nothing&ELE_NM=element%3A%2F%2F.is-cert-list-check&ELE_TARGET=%2Fcomp%2Fmnu%2Fmnu_001.html
선택 환경으로 실행
E-04

실행액션은 정상이나, 매핑에 없는 파라미터를 요청

기대 동작: 알 수 없는 페이지 모달 표시

실행 URL
ssem://run?scheme=openModal&ELE_NM=element%3A%2F%2F.nothing&ELE_TARGET=%2Fcomp%2Fmnu%2Fmnu_001.html
선택 환경으로 실행
E-05

실행액션 정상 및 매핑 파라미터이나, 매핑 페이지 미존재

기대 동작: 404 페이지 표시

실행 URL
ssem://run?scheme=openModal&ELE_NM=element%3A%2F%2F.cd80_t001&ELE_TARGET=%2Fcomp%2Fmsg%2Fmsg_101_80.html
선택 환경으로 실행
